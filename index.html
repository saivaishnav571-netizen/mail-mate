              The pipeline

              every message.

              No black box and no mailbox takeover. Each stage does one job, keeps its output visible, and hands the message to the next stage.

              Before you start

              Fair questions.

              The demo is deliberately small. Here is exactly what it does and does not do.

              Does MailMate connect to my real inbox?

              Not in this build. The demo uses a bundled 26-message inbox or a file you choose. There is no OAuth flow, no mailbox password field, and no server receiving your messages.

              What does the AI actually do?

              A TF-IDF + multinomial logistic regression classifier, trained in the browser from 125 labelled examples, scores each message against the five buckets. Around it, TF-IDF semantic search, a sentiment and urgency lexicon, extractive summaries, a priority score and tone-aware draft rewrites all run locally. The rule engine and the model are shown side by side so you can judge both.

              Does the AI call a cloud API?

              No. There is no API key, no model download and no network request. The training set is bundled with the page, the model is fitted on load, and the cross-validation metrics are computed in the same tab. That keeps the demo deterministic and keeps your inbox on your device.

              What are the five buckets?

              Important, Academic, Internship, Personal and Spam. The order matters: Important is the default for messages with weak signals so a person can check them, while Spam needs a clear combination of giveaway phrases.

              How are deadlines and actions found?

              Dates are scored by nearby cues such as “by”, “before” and “due”, then the strongest candidate wins. Actions come from imperative sentences and requests such as “please upload” or “can you confirm”. Both are heuristics, visible for you to correct.

              Can it send email on its own?

              No. Every reply goes through an approval card with a required checkbox. The demo then simulates the send and records it on the page. No message leaves the browser, and there is no auto-send option.

              What happens when I upload a file?

              The file is read with the browser’s File API, validated row by row, then passed through the same sorting and drafting logic. Rows missing a sender, subject or body are listed as errors instead of being guessed at.

              Is the three-dimensional scene real?

              Yes. The sorting table is a live Three.js scene with envelopes moving into five paper trays. It pauses when you ask it to, when the tab is hidden, and when the scene is off screen. If WebGL is unavailable, a still paper fallback appears.
